超节点集群操作系统 · 双门户角色侧边栏 V12

依据《超节点集群操作系统 MRD v0.5》正式角色。管理端三员优先展示，未增加 MRD 以外的角色；按产品一级、二级菜单组织，并保留万全现有功能。

角色边界：系统管理员负责资源、调度与运行维护；安全管理员负责安全配置与授权；安全审计员只读查询和分析审计信息，不能修改日志及安全策略。运营管理员为独立业务角色，排在三员之后；按授权维护业务组织、项目和额度，不管理人员账户与安全授权。API Key 调用与用量统计关联计量、费用分析和北向 API，第三方消纳另按 OM-021 的演进范围确认。Portal 的 Token 消费者属于凭据主体，不管理最终用户。页面的 P0/P1/P2/Demo 标签取关联 MRD 需求，多个标签表示同页关联不同优先级。
